Final Project Phase 1
Engine Version: Unreal Engine 5.7 (UE5)

How to Open the Project:
1. Locate the .uproject file in the project folder
2. Double click to open in Unreal Engine
3. If prompted to rebuild modules, click Yes
4. Once loaded, open the level from the Content Browser if it doesn't open automatically
   
How to Run:
. Press the Play button in the Unreal toolbar
. Both Blueprint actors will automatically begin animating, player input not required
. To stop, press the Stop button or Escape

No special configuration is required. All systems are self-contained and run on Play.
